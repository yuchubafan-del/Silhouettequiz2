# キャラクター シルエットクイズ 〜だ〜れだ？〜 (4大ゲームモード対応)

Webブラウザで手軽に遊べる、**SQLiteデータベース**を活用した本格的なキャラクターシルエットクイズゲームです。
**「ポケモン」「妖怪ウォッチ」「ドラゴンクエスト」「スーパーマリオ」**の4大人気ゲームシリーズ（全1,233体）を収録！
キーボード手入力による直感的な回答システムを搭載しています。

---

## 🎮 ゲームの主な特長

- **完全手入力回答（キーボード特化）**:
  - ひらがな・カタカナ、大文字・小文字、全角・半角のゆらぎを自動吸収（例: `じばにゃん`、`ジバニャン` のどちらでもOK）。
  - サジェスト（入力候補）付きでスムーズに入力できます。
  - **Enterキー** で即回答、正解後も **Enterキー** でサクサク次の問題へ進めます。
- **惜しい判定**:
  - メガシンカやキョダイマックスに基本名で答えた場合や、スライム系に「スライム」と答えた場合に「💡 おしい！」とアドバイスが表示されます。
- **📖 キャラクター図鑑（コレクション機能）**:
  - クイズで正解したキャラクターは、データベースの `player_collection` テーブルに自動記録され、カラーで解放されます。
  - ポケモン・妖怪ウォッチ・ドラクエ・マリオそれぞれのタブでコレクション率を確認できます。
- **🏆 ハイスコアランキング＆分析**:
  - プレイ終了時にスコアを `leaderboard` テーブルに保存。
  - データベース集計で「正解率」や「間違えやすいキャラクターTOP5」などを自動分析。
- **🔍 SQL探検コンソール**:
  - ゲームの裏側で動いているSQLiteデータベース（`characters` テーブル）に対して、直接SQLクエリ（SELECT文）を実行できます！

## 🗄️ データベース設計 (`pokemon_quiz.db`)

### 1. `characters` (全キャラクター共通マスター)
- `id`: 一意のキャラクターID
- `category`: カテゴリ (`pokemon` / `yokai` / `dq` / `mario`)
- `identifier`: 識別名
- `name_ja`: 日本語名
- `name_en`: 英語名
- `form_type`: 姿・形態 (`normal` / `mega` / `gmax` 等)
- `attribute1`: 主属性（タイプ / 種族 / 系統 / 陣営）
- `attribute2`: サブ属性
- `genus`: 分類・肩書き
- `flavor_text`: 解説・ヒント文
- `image_url`: シルエット用画像URL（高速ローカル配信）
- `aliases`: 許容回答エイリアス

### 2. `player_collection` (図鑑・クリア記録)
- 各キャラクターのクリア回数・初回/最新クリア日時

### 3. `leaderboard` (ランキング)
- プレイヤー名、スコア、正解数、最大コンボ、モード名

### 4. `quiz_logs` (解答履歴ログ)
- 統計分析用データ

## 🚀 起動方法

### 方法1: ダブルクリックで簡単起動
フォルダ内の **`start.bat`** をダブルクリックすると、サーバーが立ち上がり、自動的にブラウザでゲームが開きます。

### 方法2: コマンドラインから起動
```bash
python app.py
```
起動後、ブラウザで **http://127.0.0.1:5000** を開いてください。
